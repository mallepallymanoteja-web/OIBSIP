# EDA on Retail Sales Data

## Oasis Infobyte Data Analytics Internship – Level 1 Task 1

This project performs Exploratory Data Analysis (EDA) on retail sales data to identify sales patterns, customer behavior, product performance, and actionable business insights.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

### Analysis Performed
- Dataset inspection
- Descriptive statistics
- Monthly and quarterly sales trends
- Customer age-group distribution
- Gender distribution
- Product category analysis
- Quantity sold by category
- Revenue by product category
- Correlation analysis
- Additional visualizations
- Business insights and recommendations

### Conclusion
The analysis provides useful insights into customer demographics, product performance, sales trends, and relationships between numerical variables. These findings can help businesses improve marketing strategies, inventory planning, and revenue generation.
